🎨 Дизайн-система и библиотека компонентов

Библиотека компонентов

Tailwind CSS + Headless UI patterns (кнопки, бейджи, инпуты, карточки, модальные окна, алерты).

Цветовая палитра

Slate (фон/текст), Indigo (акцент #4f46e5), Rose (#e11d48 баги), Emerald (#059669 фичи), Amber (#d97706 триаж).

Типографика и отступы

Шрифт Inter. 4px/8px модульная сетка (gap-4, p-6, space-y-3). Четкая иерархия H1-H4, body, caption.

Доступность (a11y)

Видимый outline при навигации с Tab (`focus:ring-2`), aria-describedby для ошибок, полная поддержка клавиатуры.
