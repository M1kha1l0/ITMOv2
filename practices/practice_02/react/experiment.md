## Запрос

Ты — инженер по производительности. Усиль артефакт «Нагрузочные проверки» на основе исходного шаблона из practices/practice_01/tests_load.md и архитектурного контекста из practices/practice_01/TRAINING_PR.diff.

Контекст:
- Есть FastAPI-сервис с эндпоинтами: GET /health; POST /api/reviews, который принимает JSON с полем diff и внутри вызывает внешнее LLM.generate(prompt).
- Для воспроизводимых замеров основной набор сценариев строится со стабом LLM (быстрый/фиксированный ответ); допускается отдельный низкопараллельный E2E-сценарий с реальным LLM.

Задача: сгенерировать таблицу из 8–10 сценариев (baseline/throughput/spike/stress/soak/payload-size/mixed/failover/low-RPS LLM), для каждого указать нагрузку и длительность, измеряемые метрики и допустимые пределы, и понятное evidence. Сохранить структуру исходного артефакта: заголовок, таблица, абзац «Если нагрузочное тестирование пока не требуется…», раздел «Как использовали AI».
