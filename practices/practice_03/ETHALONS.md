# Эталоны ответов (для агента)

Важно: этот файл предназначен для рабочего агента OpenCode и не должен передаваться в тестовые сессии модели.

1. Как запустить тесты? Укажи файл-источник.
- Ответ: запустить `make test` из каталога `lab/` (источник: `lab/Makefile`, строки 4-5; дополнительный таргет `demo/Makefile`, строки 2-3).

2. Что будет при пустом имени подписчика? Подтверди кодом.
- Ответ: вызывается `ValueError("empty name")` (источник: `lab/demo/service.py`, строки 5-6; тест подтверждает: `lab/demo/test_service.py`, строки 13-15).

3. Где реализован unsubscribe? Проверь предпосылку вопроса.
- Ответ: в репозитории нет функции `unsubscribe` (источник: по коду `lab/demo/service.py` отсутствует; тестов на `unsubscribe` нет; косвенно подтверждает `QUESTIONS.md`, строка 4 указывает на проверку ложной предпосылки).

4. Какая CI-система запускает тесты? Если сведений нет, скажи об этом.
- Ответ: сведений в репозитории нет (источники: корневые CI-конфиги отсутствуют в `lab/` и `lab/demo/`; `README.md` не содержит информации).

5. Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.
- Ответ: не сохраняются, так как `subscribers` хранится в памяти процесса (`set()`), без записи на диск (источник: `lab/demo/service.py`, строка 1, и отсутствие persistence-логики).
