# REPORT

Аппаратное окружение
- CPU: AMD Ryzen 7 3700X (8C/16T)
- RAM: 32 GiB (доступно ~20 GiB)
- GPU: NVIDIA GeForce RTX 3070, 8 GiB VRAM (драйвер 550.163.01), CUDA 12.4

Модель и конфигурация
- Модель: Ollama qwen3.5:4b
- ID модели (ollama list): 2a654d98e6fb
- Кол-во параметров: ~4.7B
- Квантизация: Q4_K_M
- Контекст: 4096 (Modelfile), 65536 для рабочего агента (Modelfile.agent)
- Температура: 0.2
- Провайдер: OpenCode, провайдер ollama через openai-compatible API (baseURL http://localhost:11434/v1)

Обоснование выбора
- 4B-модель даёт приемлемую скорость и потребление памяти на ноутбуках/ПК среднего уровня.
- Низкая температура для фактуальных ответов по коду.
- Умеренный контекст 4k для тестовых сессий; расширенный 64k для рабочего агента для подготовки эталонов.

Подготовка окружения
- Modelfile и Modelfile.agent настроены под qwen3.5:4b с соответствующим контекстом и температурой.
- opencode.json в lab/demo настроен на локальную модель и агент test-runner с правами только чтения. ETHALONS.md исключён из чтения тестовым агентом.
- make test проходит успешно.

Результаты тестовых вопросов
- Сессии запускались из директории lab/demo: каждый вопрос отдельно через OpenCode (агент test-runner).
- Ответы и сравнение с эталонами зафиксированы в practices/practice_03/RESULTS.md.

Ограничения и наблюдения
- Модель иногда игнорирует доступные файлы, если не подсветить их явно (пример: вопрос про пустое имя). Требуется системное напоминание в repo-system.txt и корректное разрешение на чтение.
- Производительность стабильная; VRAM использовался в рамках доступного бюджета.
