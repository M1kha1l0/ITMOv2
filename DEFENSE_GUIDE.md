## 6. Архитектурные вопросы экзаменатора и ответы уровня Staff/Principal

### В: Почему в Практике 7.1 выбраны Claude Sonnet 4.5 и GPT-4o-mini?
> **О:** *«Это классический паттерн двухуровневого анализа (Two-Tier Model Routing). `openai/gpt-4o-mini` — быстрая и экономичная модель для базового синтаксического чека и триажа Issues. `anthropic/claude-sonnet-4.5` обладает передовым качеством reasoning для поиска сложных логических уязвимостей (XSS, race condition, валидация полей моделей). Разделение команд позволяет команде явно выбирать глубину и стоимость ревью.»*

### В: Что происходит, если PR содержит огромный diff на 5000 строк?
> **О:** *«В узле `Parse Diff Into Blocks` предусмотрены лимиты безопасности: игнорируются нерелевантные файлы (lockfiles, minified css/js, картинки), а максимальное количество блоков ограничено константой `MAX_BLOCKS = 12`. Если diff превышает лимит, сценарий добавляет в ревью предупреждающий баннер: „Diff превысил лимит размера: проверены первые 12 ключевых блоков“, предотвращая переполнение контекстного окна LLM и сбои по таймауту.»*

### В: Почему для Issue с `needs-triage` строго запрещено оставлять комментарий?
> **О:** *«Это ключевое требование бизнес-процесса технической поддержки: если алгоритм не уверен в классификации (`confidence < 0.8`), публиковать пользователю галлюцинацию или неверный статус недопустимо — это разрушает доверие к сервису. Issue молча помечается лейблом `needs-triage` и попадает в очередь дежурного саппорт-инженера для ручной верификации.»*

### В: Как работает расчёт недели к неделе (Week-over-Week) в отчёте?
> **О:** *«В n8n Data Table `weekly_stats` хранится история снимков каждой недели с датой понедельника. Узел `Get_Previous_Week_Stats` загружает последнюю историческую запись, а Code node `Calculate_Weekly_Diff` вычисляет абсолютные изменения: `Δ = current - previous`. Затем эти дельты передаются в prompt LLM, которая на их основе пишет осмысленную бизнес-интерпретацию динамики спринта.»*

### В: Почему клиентские тесты в Практике 8 мокируют сервер, а не стучатся в живой n8n?
> **О:** *«В соответствии с принципами тестирования (Test Isolation & Hermetic Testing) юнит- и интеграционные тесты клиентской части не должны зависеть от внешнего сетевого окружения, доступности сторонних серверов или баланса токенов LLM. Подмена ответов через `vi.spyOn(global, 'fetch')` позволяет детерминированно протестировать все пограничные состояния: задержки сети, HTTP 500, пустые списки и защиту от race conditions.»*
